# 财务模型修复任务指令：资产负债表平衡性排查与修复

## 一、任务背景

`model.xlsx` 为医疗行业五年期（2024–2028）多表联动集成财务模型。当前资产负债表平衡校验行（资产合计 − 负债及所有者权益合计）在预测期偏离零值，且偏差已传导至下游估值模块与净利润指标，导致输出失真。本次任务为**定位勾稽断点、修复逻辑错误、恢复模型完整性**，不涉及重新搭建或调整经营假设。

## 二、数据源与产出位置

- **数据源（输入）**：`model.xlsx` 全部工作表，重点覆盖资产负债表、利润表、现金流量表及各明细附表（折旧摊销、营运资本、债务及利息、股东权益变动）、估值模块。
- **产出位置**：
  1. 修复后的模型文件，另存为 `model_repaired.xlsx`（保留原文件作为基线，不得覆盖）；
  2. 在模型内新增"修复说明"工作表，逐项记录：断点位置、根因、修复方式、修复前后校验值；
  3. 简要修复纪要，供估值与财务分析团队复核下游结果变化。

## 三、排查范围与优先级

按以下勾稽链路逐环排查，直至定位全部断点：

1. **现金流勾稽**：现金流量表期末现金余额是否等于资产负债表现金科目（分年度核对2024–2028）；
2. **留存收益滚动**：期初留存收益 + 当年净利润 − 分红 = 期末留存收益；
3. **净利润传导**：利润表净利润与现金流量表间接法起点、股东权益变动表取数是否一致；
4. **资产滚动逻辑**：固定资产/无形资产的"期初 + 新增 − 折旧摊销 − 处置"是否与折旧附表一致；医疗行业

- 在工作目录下将最终工作簿另存为 **`output.xlsx`**（保留全部 sheet 与结构）。
- 评分为 OJ 严格匹配：对 `output.xlsx` 用 LibreOffice 重算后，
  **所有应修改单元格的计算值必须正确，且所有不应改动的单元格保持不变**；
  多改、少改均判 0 分（无部分分）。数值比较保留两位小数。
- 验证标准：资产负债表 `Check` 行各期须为 0（|误差| < 0.01）。
