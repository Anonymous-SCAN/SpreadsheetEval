# 财务模型修复任务指令：资产负债表平衡性排查与修复

## 一、任务背景

医疗行业五年期（2025–2029）集成财务模型（model.xlsx）当前存在资产负债表不平衡问题：平衡检查行在部分或全部预测年度出现非零值，且误差已传导至下游，导致净利润与估值结果失真。需定位根因、完成修复并恢复三表勾稽关系。

## 二、数据来源与产出位置

- **数据来源**：model.xlsx 内各模块——经营假设、利润表、资产负债表、现金流量表、估值模块及其相互引用关系。
- **产出位置**：在原工作簿内完成修复并另存交付版本；同时在模型中保留或增设平衡检查行，逐年度展示资产与负债及所有者权益的差额，作为验收依据。

## 三、执行步骤

1. **定位失衡区间**：确认不平衡首次出现的年度（2025 年起逐年核查），判断为单一年度断点还是全期累计传导。
2. **排查典型断点**（按优先级）：
   - 现金流量表期末现金与资产负债表货币资金是否一致；
   - 净利润是否完整结转至留存收益（含分红、少数股东损益的正确处理）；
   - 折旧摊销、资本开支与固定资产/无形资产净额的滚动勾稽；
   - 营运资本变动（应收、存货、应付——重点关注医疗行业特有的医保回款周期、高值耗材库存与往来款）与资产负债表对应科目的一致性；
   - 借款发生额、偿还与利息计提在负债端和费用端的同步性；
   - 是否存在跨年复制导致的引用错位、漏项或符号错误。
3. **修复原则**：仅修正公式引用与勾稽断点，不得通过硬编码差额、反向凑数或调整经营假设的方式强行压平。
4. **下游联动确认**：修复后重算全模型，确认净利润、自由现金流及估值结果自动更新且无循环引用警告。

## 四、边界条件

- 不得改动已审定的经营假设与业务预测逻辑；
- 不得删除或隐藏检查行，不得修改检查行口径；
- 各年度独立平衡，不允许以跨年对冲方式掩盖单年失衡；
- 保持原有表结构与命名规范，新增辅助核查内容须清晰标注。

## 五、验证与验收标准

1. 2025–2029 全部年度资产负债表检查行差额绝对值 **小于 0.01**（即视为平衡）；
2. 现金流量表期末现金与资产负债表货币资金逐年一致，差异小于 0.01；
3. 期初留存收益加当年净利润减分红等于期末留存收益，逐年成立；
4. 净利润与估值模块输出随修复自动重算，无滞留旧值、无循环引用；
5. 交付修复版工作簿，并附简明根因说明（失衡位置、原因、修复方式）。

## 交付要求（评分口径）
- 在工作目录下将最终工作簿另存为 **`output.xlsx`**（保留全部 sheet 与结构）。
- 评分为 OJ 严格匹配：对 `output.xlsx` 用 LibreOffice 重算后，
  **所有应修改单元格的计算值必须正确，且所有不应改动的单元格保持不变**；
  多改、少改均判 0 分（无部分分）。数值比较保留两位小数。
- 验证标准：资产负债表 `Check` 行各期须为 0（|误差| < 0.01）。
