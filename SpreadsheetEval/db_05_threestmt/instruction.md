# 医疗企业集成财务模型勾稽修复任务指令

## 一、任务背景与症状
某医疗企业多年度集成财务模型（预测期 2025–2028）当前存在资产负债表失衡：勾稽检查行在预测年度不为零，即资产与负债加所有者权益不相等。因三表联动传导，下游净利润与估值输出已被污染，现阶段模型结果不可用于经营决策或对外报告。本次任务为调试与错误修复，不涉及业务假设重设。

## 二、数据源
唯一数据源为 **model.xlsx**，为多单页集成模型，涵盖假设、利润表、资产负债表、现金流量表及营运资本、固定资产与折旧摊销、债务与利息、权益、估值等配套明细页。历史实际数以簿内既有数据为准，不引入外部数据。

## 三、排查与修复范围
1. **定位失衡**：确认首个失衡年度及金额，判断为逐年累积（存量错误）还是单年突变（流量遗漏）。
2. **三表联动核查**：
   - 净利润是否完整结转至权益（留存收益），分红、其他综合收益处理是否一致；
   - 现金流量表期末现金与资产负债表货币资金是否一致，经营、投资、筹资三类现金流是否完整覆盖资产负债表各项期间变动；
   - 营运资本：应收（含医保结算款）、存货、应付、合同负债的变动与现金流量表逐项对应；
   - 长期资产：资本开支、在建工程转固、折旧摊销与明细表一致；研发支出资本化与费用化归集正确；
   - 债务与租赁：借款增减、利息计提与支付、租赁负债及使用权资产同步；政府补助与递延收益确认、摊销完整；
   - 权益：股本、资本公积、少数股东权益变动完整无遗漏。
3. **行业重点关注**：医保应收账期与回款、带量采购下的存货与减值、设备融资租赁、政府补助。
4. 修复仅针对链接、传导与勾稽逻辑错误，恢复模型自动计算链条。

## 四、边界条件（红线）
- 不得修改历史已审定实际数及既定业务假设（收入增速、毛利率、费用率、税率、资本开支计划等）；
- 禁止以新增"平衡项/其他"硬编码强行配平，禁止删除或覆盖勾稽检查行；
- 保持既有工作表结构、命名与跨页引用关系不变；
- 如涉及利息—现金循环联动，仅在模型已启用迭代计算的前提下保留，否则按原设计修复。

## 五、产出位置
- 在原 **model.xlsx** 内完成修复并交付，模型结构保持不变；
- 在簿内说明区域（或新增"变更说明"页）记录：失衡原因定位、修复点清单（按工作表与业务事项描述）、修复前后各年检查行数值。

## 六、验证标准（全部通过方可交付）
- 2025–2028 各年资产负债表勾稽检查行绝对值 **< 0.01**（与模型计量单位一致），历史年份保持为零；
- 现金勾稽：各年现金流量表期末现金与资产负债表货币资金差异 < 0.01；
- 利润勾稽：净利润减分红与留存收益变动一致，差异 < 0.01；
- 估值页全部引用修复后数据，无引用失效、除零等错误值，企业价值、股权价值、每股价值等核心输出可正常重算；
- 全簿重算后无新增错误值、无断链。

## 交付要求（评分口径）
- 在工作目录下将最终工作簿另存为 **`output.xlsx`**（保留全部 sheet 与结构）。
- 评分为 OJ 严格匹配：对 `output.xlsx` 用 LibreOffice 重算后，
  **所有应修改单元格的计算值必须正确，且所有不应改动的单元格保持不变**；
  多改、少改均判 0 分（无部分分）。数值比较保留两位小数。
- 验证标准：资产负债表 `Check` 行各期须为 0（|误差| < 0.01）。
