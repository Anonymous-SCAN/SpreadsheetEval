# 财务模型搭建任务指令：制造业五年期三表集成模型

## 一、任务概述

为一家制造业企业搭建五年期（2025–2029）三表联动财务预测模型，并基于预测现金流完成DCF估值，产出**企业价值**与**每股价值**两项核心结果。全部成果交付于工作簿 **model.xlsx** 中，预计需完成约 **164** 个数据单元的构建。

## 二、交付结构

| 工作表 | 职责 |
|---|---|
| IncomeStatement | 五年利润表预测：收入、成本、费用、税项至净利润 |
| CashFlow | 五年现金流量表：经营、投资、筹资三大活动，得出期末现金 |
| BalanceSheet | 五年资产负债表：与利润表、现金流量表全面联动 |
| DCF（估值区） | 承载两项头条产出：**企业价值**、**每股价值** |

## 三、数据源与假设输入

- 历史财务数据及经营假设以既有输入区为准（收入增速、毛利率、费用率、税率、资本开支、折旧政策、营运资本周转天数、净债务、股本数、WACC、永续增长率），不得自行篡改历史数与假设数。
- 制造业特性须体现：存货、应收、应付按周转天数驱动；固定资产按"期初＋资本开支－折旧"滚动；产能相关资本开支与收入规模匹配。

## 四、建模业务逻辑要求

1. **三表必须闭环联动**：净利润自利润表流向现金流量表与留存收益；折旧摊销为非现金加回项；营运资本变动由资产负债表对应科目推导；现金流量表期末现金即资产负债表货币资金。
2. 预测口径仅覆盖 2025–2029 五个年度，历史列只引用、不改动。
3. 估值采用 FCFF 折现：以 WACC 折现五年显性期自由现金流并加计永续终值，得出**企业价值**；扣除净债务后除以稀释股本，得出**每股价值**，两项结果须呈现在 DCF 工作表对应命名产出位。

## 五、边界条件与验证标准

- **资产负债表逐年平衡**：资产 = 负债＋所有者权益，各年误差 **< 0.01**。
- **现金勾稽一致**：现金流量表期末现金与资产负债表货币资金逐年相等，误差 < 0.01。
- **净利润勾稽一致**：利润表净利润、现金流量表起点净利润、留存收益滚动所用净利润三者同源。
- 预测期内现金余额不得出现无解释负值；累计折旧不得超过固定资产原值。
- 估值参数合理：永续增长率须低于 WACC，且二者均处于行业合理区间。
- 计量单位与币种全簿统一；除假设区外不得硬编码数值，所有计算单元须由业务逻辑驱动。
- 交付范围以约 164 个构建单元为限，全部填满且无残留空项、无断链引用。

## 六、验收清单

- [ ] 五年三表完整、逐年平衡并通过勾稽校验
- [ ] DCF 工作表正确输出企业价值与每股价值
- [ ] 假设改动可全链路传导，模型可复算、无循环报错
- [ ] 历史数据与输入假设未被覆盖

完成后提交 model.xlsx 供复核。
