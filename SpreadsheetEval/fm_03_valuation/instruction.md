# 财务建模任务指令：地产公司五年预测与估值模型

## 一、任务目标

在 `model.xlsx` 工作簿中，为标的地产企业搭建 2025–2029 年预测期的三张核心工作表：**WorkingCapital（营运资本）**、**CashFlow（现金流量表）**、**DCF（折现现金流估值）**，全部待建内容约 128 个单元格。最终交付两项核心结果：**企业价值（EV）** 与 **每股价值**（后者须以"每股价值"命名并置于 DCF 工作表醒目位置）。

## 二、数据来源与依赖

- **历史数据与预测假设**：取自工作簿内已有的历史财务报表及假设页（收入、成本、资本开支、折旧摊销、税率、付息负债、股本等）。所有预测行应引用既有假设驱动，不得硬编码可在假设页找到的参数。
- **表间衔接**：WorkingCapital 的输出（各期营运资本及变动额）直接驱动 CashFlow 的经营活动现金流；CashFlow 与利润表、资产负债表的勾稽结果（自由现金流、净负债）驱动 DCF。
- 如关键假设缺失，在对应工作表备注列标注"假设待定"并采用行业惯例值（如永续增长率 2%–3%），不得留空。

## 三、建模要点

### 1. WorkingCapital（营运资本）
- 覆盖地产行业核心科目：**存货（开发成本/开发产品）、应收账款、预付款项、应付账款/应付票据（工程款）、合同负债（预收售房款）**。
- 以周转天数或占收入/成本比例法预测各科目期末余额，计算各年度营运资本及环比变动额，供现金流量表引用。
- 注意地产行业合同负债体量通常较大，须在营运资本中单独列示，不得并入应付账款。

### 2. CashFlow（现金流量表）
- 采用**间接法**：由净利润出发，加回折旧摊销，调整营运资本变动，得经营活动现金流。
- 投资活动反映资本开支；筹资活动反映有息负债增减、利息支付及股利分配。
- 期末现金及现金等价物须与资产负债表货币资金科目完全衔接。

### 3. DCF（折现现金流估值）
- 基于无杠杆自由现金流（FCFF）折现：由 EBIT×(1−税率) 出发，加回折旧摊销、扣除资本开支与营运资本增加额。
- 折现率采用 WACC，折现方式明确（建议年中折现并在表内注明）。
- 终值采用永续增长法，永续增长率不得高于长期名义 GDP 增速（建议 ≤3%）。
- 价值桥：预测期现金流现值 + 终值现值 = **企业价值**；企业价值 − 净债务（及少数股东权益，如适用）= 股权价值；股权价值 ÷ 总股本 = **每股价值**。

## 四、边界条件

- 预测期严格限定为 **2025–2029 五个年度**，不向前追溯重述历史，不在表内延伸至 2030 年及以后（终值除外）。
- 单元格建设总量控制在 **128 个左右**，优先保证勾稽链完整，装饰性格式不计入。
- 所有跨表引用须指向本工作簿内既有工作表；禁止引入外部工作簿链接。
- 金额为负的科目（如净债务为净现金时）须在价值桥中正确处理符号，不得强制取正值。

## 五、验证标准（交付前必须逐项通过）

1. **现金勾稽**：现金流量表各年期末现金与资产负债表对应年度货币资金一致，误差 < 0.01。
2. **资产负债表平衡**：资产 = 负债 + 所有者权益，各年误差 < 0.01。
3. **营运资本一致性**：现金流量表中的营运资本变动额与 WorkingCapital 表计算的变动额逐年一致，误差 < 0.01。
4. **DCF 合理性**：
   - 终值现值占企业价值比例处于合理区间（一般 50%–80%，超出须书面说明）；
   - 隐含估值倍数（EV/EBITDA 等）与地产行业可比公司区间无明显背离；
   - 每股价值 = 股权价值 ÷ 总股本，计算链条可逐层追溯，误差 < 0.01。
5. **完整性**：DCF 表中"每股价值""企业价值"两项结果非空、非零、无错误值。

完成后请提交 `model.xlsx`，并在 DCF 工作表顶部以备注形式列示关键假设（WACC、永续增长率、股本数）及上述五项验证的通过状态。
